# Лабораторный журнал проекта на тему: "Анализ циркадной динамики экспрессии генов, связанных с клеточным метаболизмом, на основе временного RNA-seq профилирования" по предмету "Практикум по биоинформатике"
## Введение
Все расчеты производились на компьютере с установленным графическим окружением Linux и следующими характеристиками:
- PC:
    ```

    GPU: AMD Radeon 780M
    ```

Так как компьютер оснащен графическим интерфейсом, такие действия как перемещение файлов между директориями, распаковка архивов и скачивание данных производились с использованием графических инструментов. Весь пайплайн анализа реализован на языке программирования python с использовнием таких библиотек как pandas, numpy, re, matplotlib.
## Шаг 1 - Поиск и подготовка исходных данных
Для подтверждения или опровержения поставленной гипотезы необходим набор данных, демонстрирующий суточное изменение экспрессии генов. В качастве такового был выбран набор данных [GSE74439](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE74439) и файлы [GSE74439_DMSO_genes.attr_table.txt](https://github.com/Vanyush/bioinf_workshop/blob/main/GSE74439_DMSO_genes.attr_table.txt) (аннотация образцов) и [GSE74439_DMSO_genes.fpkm_table.txt](https://github.com/Vanyush/bioinf_workshop/blob/main/GSE74439_DMSO_genes.fpkm_table.txt) (матрица FPKM-нормализованных индексов экспресии). Набор данных представляет собой контрольную группу соответствующего исследования. Данный надор данных был выбран в качестве основного для анализа, так как прежставляет собой группу клеток, на которые не воздействовали во время проведения исследования.

Для первичной подготовки данных было необходимо преобразовать данные из файлов в датафрейм, пригодный для дальнейшего анализа. Таким образом была написана функция `parse_raw_data`, принимающая путь к файлам аннотации и матрицы индексов экспресии и возвращающая структуру данных `pd.Dataframe`, где первый столбец - названия генов, а последующие - данные об экспресии в течение 48 часов с интервалом в 4 часа. 
## Шаг 2 - Логарифмирование и оценка цикличности эксперсии контрольных генов
Для сглаживания уровня эксперсии и более наглядной оценки относительного изменения была написана функция `expr_log`, возвращающая датафрейм с логарифмированными (как двоичный логарифм суммы индекса эксперсии и единицы) индексами эксперсии. Далее была написана функция `gene_plot`, сохраняющая график зависимости логарифма экспрессии от времени, в которое она оценивалась. 

Для того, чтобы оценить пригодность набора данных для дальнейшего анализа было принято решение графически оценить цикличность изменения экспрессии генов *CLOCK*, *BMAL1*, *PER1*, *PER2*, *CRY1* и *CRY2*. Данные гены являются "маркерными" для анализа суточной эксперссии, так они задают петлю транскрипции-трансляции и запускают транскрипцию "ритмичных генов". Скрипт показал, что ген *BMAL1* отсутствует в выбранном датасете. Таким образом, анализ гена *BMAL1* было решено пропустить. Анализ остальных генов показал, что паттерн суточной экспрессии сохранялся (рис. 1-5). На основе этого был сделан вывод о пригодности набора данных для дальшейшего анализа.
